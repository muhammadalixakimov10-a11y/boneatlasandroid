# Bone Atlas — Android loyiha

Bu loyiha siz yuborgan Bone Atlas veb-ilovasini Android WebView ichida ochadi. 3D skelet (`skeleton.glb`), Three.js to'plami va progress saqlash skripti ilova ichiga joylangan. O'quv jarayoni va natijalar telefonning lokal xotirasida saqlanadi.

## APK olish (GitHub orqali, kompyutersiz ham)
1. `BoneAtlasAndroid.zip` faylini GitHub'ga yangi repository sifatida yuklang.
2. Repository'da **Actions** bo'limini oching.
3. **Build Android APK** workflow'ini tanlab **Run workflow** bosing.
4. Tugagach, ishga tushgan workflow ichidagi **BoneAtlas-debug-apk** artifact'ini yuklab oling.
5. APK'ni Android telefonda ochib o'rnating. Telefon sozlamalarida shu manbadan ilova o'rnatishga ruxsat so'ralishi mumkin.

## Android Studio orqali
Papka Android Studio'da ochiladi. Gradle sync tugagach **Build > Build Bundle(s) / APK(s) > Build APK(s)** ni tanlang.

Eslatma: Google Fonts va ixtiyoriy tashqi resurslar internet talab qilishi mumkin. Asosiy 3D model va JavaScript kutubxonasi ilovaning ichida.
